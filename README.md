# Американское произношение без акцента

Курс американского произношения **без акцента** (General American English) на русском языке: 6 фаз, 38 уроков, справочник IPA, недельный тренажёр и протокол самозаписи.

Цель — поставить артикуляцию каждого звука GA, довести речь до естественного ритма и связности и научиться слышать себя со стороны.

## Что внутри

- **38 уроков** — от речевого аппарата и IPA до связной речи, интонации и финального ассессмента.
- **Интерактивная таблица IPA** — все звуки американского английского с примерами.
- **Тренажёр на 7 дней** — ежедневные 35–40-минутные сессии из 6 блоков (разминка, минимальные пары, фразы, связная речь).
- **Протокол самозаписи** — 5-шаговый протокол, чек-лист по 5 критериям, дневник и встроенный рекордер (`MediaRecorder`).
- **Озвучка (TTS)** — кнопки прослушивания у каждого примера произношения (Web Speech API, `en-US`).
- **Тёмная/светлая тема** — переключатель system / light / dark с сохранением в `localStorage`.

## Локальный запуск

Сайт — статический, без сборки. Поднимите любой HTTP-сервер из корня проекта — Node.js-варианты:

```bash
# через npx (без установки зависимостей)
npx serve site -l 8000

# альтернатива
npx http-server site -p 8000
```

Либо через Python (если установлен):

```bash
python -m http.server 8000
```

Затем откройте <http://localhost:8000/>.

> Рекордеру на странице `recorder.html` нужны HTTPS или `localhost` (доступ к микрофону).

## Проверка озвучки

Перед коммитом правок в разметку запускайте валидатор — он сверяет кнопки `.audio-btn` с манифестом:

```bash
python tools/audio_validate.py
```

Ожидаемый результат: `0` отсутствующих ключей, `0` IPA в манифесте, `0` inline-`onclick`.
Вспомогательный инвентаризатор: `python tools/audio_audit.py`.

## Разработка

Все правила размещения файлов, верстки, навигации и озвучки описаны в [AGENTS.md](AGENTS.md). Ключевое:

- готовый контент — **только в `site/`**;
- никаких ссылок на `.md` из HTML-файлов сайта;
- кнопки озвучки — только `<button class="audio-btn" data-audio-key="…">`, ключ обязан быть в `site/assets/audio-manifest.js`;
- нотация транскрипций: `/ɹ/`, `/ɝ/`, `/ɚ/`, `/iː/`, `/ɑː/` (без британских символов).
