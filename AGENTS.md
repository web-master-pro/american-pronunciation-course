# Руководство для AI-агентов (AGENTS.md)

Проект: **EnglishPhonetics-4 — Курс американского произношения без акцента**  
Целевой диалект: **General American English (GA)**  
Язык подачи материала: **Русский** (лингвистические термины, примеры слов и транскрипции — на английском с IPA).

---

## Архитектура проекта и правила размещения файлов

### 1. Папка деплоя: `site/`
**Весь готовый контент курса для размещения на хостинге/веб-сервере находится ИСКЛЮЧИТЕЛЬНО в папке `site/`**.
Любые новые уроки, правки верстки, добавление стилей или справочников должны производиться **только внутри `site/`**.

Структура `site/`:
- `site/index.html` — Главная страница курса (герой-блок, быстрый старт, оглавление 6 фаз, список справочников).
- `site/mission.html` — Описание миссии курса, целей, критериев успеха и границ программы.
- `site/plan.html` — Структурированный план обучения по всем 6 фазам (38 уроков).
- `site/recorder.html` — Страница-протокол самозаписи (5-шаговый протокол, чек-лист сравнения по 5 критериям, шаблон дневника, встроенный рекордер).
- `site/resources.html` — Каталог проверенных учебников, видеоканалов, словарей и тренажёров.
- `site/reference/ipa-chart.html` — Интерактивная таблица всех звуков American English IPA с примерами.
- `site/lessons/` — Уроки курса (`0001-speech-apparatus.html` ... `0038-final-assessment.html`).
- `site/assets/style.css` — Единая таблица стилей курса (стили Эдварда Тафти: удобочитаемость, типографика, адаптивность).
- `site/assets/theme.js` — Переключатель тем (system / light / dark) с сохранением в localStorage.
- `site/assets/audio.js` — Аудио-движок озвучки (Web Speech API TTS, глобальный `CourseAudio`, делегирование кликов по `.audio-btn[data-audio-key]`; graceful degradation при отсутствии `speechSynthesis`).
- `site/assets/audio-manifest.js` — Манифест озвучки `window.AUDIO_MANIFEST` (ключ → `{text}`; только орфография, без IPA).
- `site/assets/recorder.js` — Рекордер `MediaRecorder` для `recorder.html` (запись дублей, прослушивание, экспорт webm, A-B сравнение с TTS-эталоном; запись только в памяти страницы).
- `site/assets/favicon.svg` — Иконка сайта (SVG), подключается на всех страницах.

### 2. Сервисные файлы проекта (корень)
- `AGENTS.md` — Данное руководство для агентов.
- `MISSION.md` — Исходный контекст миссии и критериев успеха.
- `PLAN.md` — Исходный план программы обучения.
- `NOTES.md` — Предпочтения обучающегося и методические заметки.
- `RESOURCES.md` — Исходный перечень рекомендуемых источников.

## Стандарты верстки и навигации уроков

Все страницы уроков в `site/lessons/` строго следуют единому шаблону:

1. **Кодировка и язык:** `<html lang="ru">`, `<meta charset="UTF-8">`.
   **SEO:** на всех страницах сайта (53 шт., AUDIT, п. 8.5) обязателен `<meta name="description" content="...">` с уникальным русским описанием — новые страницы должны добавлять его сразу после строки viewport.
2. **Двухуровневая навигация:**
   - **Верхняя навигация (`<nav class="site-nav">`):**
     - Хлебные крошки: `Главная / Урок N`.
     - Ссылки на общие разделы: `План`, `Таблица IPA`, `Все уроки`.
   - **Нижняя навигация (`<nav class="lesson-pagination">`):**
     - Кнопка `[← Урок N-1]` (или заглушка `.pagination-placeholder` на Уроке 1).
     - Кнопка `[Оглавление курса]` (ссылка на `../index.html`).
     - Кнопка `[Урок N+1 →]` (или заглушка на Уроке 38).
   - **Футер (`<div class="lesson-footer">`):** рекомендации, ссылки на источники и интерактивные призывы.
3. **Выноски и врезки:**
   - Класс `.marginnote` отображается **внутри основного контента** (не выходит за пределы контейнера, выделен левым акцентным бордером).
   - Класс `.insight` — ключевая мысль урока (акцентный блок).
   - Класс `.tip` — методический совет или предостережение от типичной ошибки.
4. **Интерактивные элементы:**
   - Квизы (`.quiz`, `.quiz-options`, функция `checkAnswer(button, quizId, isCorrect)`).
   - Тренажёры на раскрытие (`.transcription-practice` с классом `.revealed`).

**Нотация транскрипций (канон курса, AUDIT Фаза 7):**
- Американский R — согласный **`/ɹ/`** (не ASCII `r`) в транскрипциях уроков и справочников; в тренажёре (`site/workout/`) исторически допускается ASCII `r` для согласного.
- R-цветные гласные — **`/ɝ/`** (ударный) и **`/ɚ/`** (безударный): никаких `-ər`/`-əɹ`/`-ɜːr`.
- Долгота гласных — знак **`ː`** (/iː/, /ɑː/); британские символы (/ɒ/, /ɜː/, /əʊ/) в GA-транскрипциях не используются (кроме явно оговорённых сравнений с RP).
- *water* = **/ˈwɑːt̬ɚ/** (GA, merged) везде.

**Аудио-слой и озвучка (AUDIT 8.1):**
- Кнопки озвучки добавляются **только** как `<button class="audio-btn" data-audio-key="KEY" ...>` — обработчик единый, делегирование в `audio.js`, индивидуальные `onclick` не используются.
- Каждому ключу `data-audio-key` обязана соответствовать запись в `site/assets/audio-manifest.js`; **в манифесте только орфографические английские строки** (TTS не читает IPA — транскрипции в манифест запрещены). Ключи: lower-case, пробелы → `-` (например `pick-it-up`).
- Новые слова для озвучки: сначала ключ в `audio-manifest.js`, потом кнопка в разметке.
- **Каждый пример произношения с транскрипцией** (слово/фраза/предложение рядом с `word /wɜːd/` или `[wɜːd]`) обязан иметь кнопку `.audio-btn[data-audio-key]` сразу после транскрипции — и при создании нового урока, и при правке существующего.
- **Голые фонемы** (`/j/`, `/ə/`, `/ɹ/` как обозначение звука без слова) кнопок не получают: TTS не читает изолированную фонему.
- Кнопка размещается **внутри** блочного элемента (`<td>`, `<li>`, `<p>`, карточка), не между закрывающими тегами строки/ячейки.
- Перед коммитом любой правки запускать `python tools/audio_validate.py` (0 missing/IPA/onclick).
- Покрытие (2026-09-30): **990 кнопок на 41 странице**, манифест **860 ключей**; инструменты `tools/audio_audit.py` (инвентаризация) и `tools/audio_validate.py` (валидатор). Итог зафиксирован в `AUDIT.md` п. 8.6.
- Страницы с озвучкой подключают в `<head>`: `<script src=".../assets/audio-manifest.js" defer>` + `.../audio.js defer` (пути по уровню вложенности).
- Протокол самозаписи и рекордер живут на `site/recorder.html`; ссылки на неё из уроков/тренажёра — только относительные (`recorder.html` / `../recorder.html`).

## Правила ссылок (КРИТИЧЕСКИ ВАЖНО)

- **Никаких ссылок на файлы `.md` из файлов сайта!**
  Все внутренние ссылки между страницами сайта должны вести исключительно на соответствующие `.html` страницы (например, `../mission.html`, `../plan.html`, `../index.html`).
- При добавлении или редактировании страниц всегда проверять валидность относительных путей.

## Быстрая проверка целостности

Для проверки ссылок в `site/` можно запустить Python-однострочник:
```powershell
python -c "
import glob, os, re
broken = []
for f in glob.glob('site/**/*.html', recursive=True):
    d = os.path.dirname(f)
    for h in re.findall(r'href=[\"\']([^\"\']+)[\"\']', open(f, encoding='utf-8').read()):
        if h.startswith(('http', '#', 'mailto')): continue
        clean = h.split('#')[0].split('?')[0]
        if clean and not os.path.exists(os.path.normpath(os.path.join(d, clean))):
            broken.append((f, h))
print('Broken links:', len(broken))
"
```
