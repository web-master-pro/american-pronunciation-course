# Ресурсы по американской фонетике и произношению

## Знания (Knowledge)

### Учебники и курсы
- [American English Phonetics and Pronunciation Practice (2nd Ed.) — Carley & Mees (Routledge, 2024)](https://www.routledge.com/American-English-Phonetics-and-Pronunciation-Practice/Carley-Mees/p/book/9781041004714)
  Комплексный учебник по артикуляционной фонетике. Охватывает все согласные и гласные, кластеры, слабые формы, связную речь. Использовать для: систематического изучения каждого звука с теорией артикуляции и практическими упражнениями.
- [Practical Pronunciation — DJ Kaiser (University of Michigan Press)](https://press.umich.edu/Books/P/Practical-Pronunciation)
  Практическое пособие с фокусом на segmentals, word stress, rhythm, intonation. Использовать для: стратегий самостоятельного обучения и упражнений на связную речь.
- [American Accent: Top 10 Essentials — Julie Cunningham (San Diego Voice and Accent)](https://courses.sandiegovoiceandaccent.com/courses/american-accent-top-10-essentials)
  Структурированный онлайн-курс от лицензированного логопеда. 10 глав: syllable stress, IPA, гласные, согласные /t/ и /r/, reductions, linking. Использовать для: базового понимания ключевых концепций американского акцента.

### Видео- и аудиоресурсы
- [Rachel's English](https://rachelsenglish.com/)
  #1 ресурс по произношению американского английского. 600+ видео, основанных на артикуляционной фонетике (фон оперного певца). Визуальные объяснения позиций челюсти, губ и языка для каждого звука. Использовать для: детальной проработки артикуляции каждого звука.
- [Sounds American (YouTube)](https://www.youtube.com/@SoundsAmerican)
  Канал от логопеда-профессионала. Видео по каждому звуку американского английского с примерами ошибок и упражнениями. Использовать для: аудиторного распознавания и практики каждого звука.
- [American English Pronunciation Workbook — UC Berkeley](https://linguistics.berkeley.edu/~kjohnson/English_Phonetics/)
  Бесплатный учебник с аудио из реальных разговоров (Buckeye Corpus). Использовать для: практики восприятия звуков в естественной речи.
- [English with Kim (YouTube)](https://www.youtube.com/@EnglishwithKim)
  Playlists для продвинутых learners: pitch, intonation, stress, thought groups. Использовать для: работы над мелодией и ритмом речи.

### Словари и инструменты
- [Merriam-Webster Dictionary](https://www.merriam-webster.com/)
  Американский словарь с аудиопроизношением. Использовать для: проверки произношения слов,IPA-транскрипции.
- [ToPhonetics.com](https://tophonetics.com/)
  Конвертер текста в IPA-транскрипцию (американский вариант). Использовать для: визуализации произношения слов.
- [Forvo — Pronunciation Dictionary](https://forvo.com/)
  Глобальный аудиословарь с записями носителей. Использовать для: сравнения произношения разных носителей.
- [Interactive American IPA Chart](https://americanipachart.com/)
  Визуальная интерактивная таблица IPA для американского английского. Использовать для: обзора всех звуков с примерами и иллюстрациями.
- [Oxford Learner's Dictionary — American Pronunciation Guide](https://www.oxfordlearnersdictionaries.com/us/about/american_english/pronunciation_american_english.html)
  Объяснение системы обозначений произношения в словаре Oxford. Использовать для: чтения IPA-транскрипций в словарях.

### Приложения
- [ELSA Speak](https://elsaspeak.com/)
  AI-приложение для фонемного анализа произношения. Бесплатный тариф. Использовать для: автоматического фидбэка на произношение каждого звука.
- [BoldVoice](https://boldvoice.com/)
  Видео-уроки от голливудских фонетистов + AI-оценка. Использовать для: структурированного тренинга с визуальными схемами артикуляции.

## Мудрость (Communities)

- [r/EnglishLearning](https://reddit.com/r/EnglishLearning/)
  Активное сообщество с вопросами по произношению. Использовать для: получения обратной связи от носителей и других learners.
- [Speech Accent Archive — George Mason University](https://accent.gmu.edu/)
  Коллекция аудио записей с акцентами со всего мира. Использовать для: сравнения акцентов и понимания своих проблемных зон.
- [SoundsAmerican.net](https://soundsamerican.net/)
  Бесплатный сайт с видео-уроками и аудио по каждому звуку. Использовать для: дополнительной практики.

## Пробелы (Gaps)

- Нет бесплатного интерактивного тренажёра для отработки конкретных проблемных звуков для русскоговорящих — компенсируем через упражнения в уроках.
- Нет единого ресурса, полностью охватывающего linking, reductions и connected speech на русском языке — компенсируем через уроки и английские ресурсы.
